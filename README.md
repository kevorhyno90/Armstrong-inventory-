# Armstrong Garage Management System

A high-performance, professional-grade management suite tailored for modern garages and inventory manifests. Built with precision for speed, reliability, and ease of use.

## 🚀 Key Features

- **Dashboard Intelligence**: Real-time sales trends, debt monitoring, and stock alerts.
- **Inventory Control**: High-precision stock tracking with brand filtering and pricing management.
- **POS (Point of Sale)**: Lightning-fast checkout workflow with automated stock decrement.
- **Debt Management**: Comprehensive debtor tracking, installment records, and balance calculations.
- **Automated Sales History**: Permanent ledger with professional PDF receipt generation and voiding capabilities.
- **Service Reminders**: Dynamic task management system for follow-ups and maintenance schedules.
- **PWA Ready**: Installable on Desktop and Mobile for a native app experience.

## 🛠️ Built With

- **React 18** + **Vite**
- **Tailwind CSS** (for high-end custom UI)
- **Framer Motion** (for smooth, cinematic transitions)
- **Lucide React** (for crisp iconography)
- **Local Storage** (Local-first persistence architecture)
- **Vite PWA Plugin** (for offline-ready installation)

## 📦 Installation & Setup

1. **Clone the repository**:
   ```bash
   git clone <your-repository-url>
   cd armstrong-garage
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```

## 📱 PWA Features

This app is a Progressive Web App. To install it:
1. Open the app in a supported browser (Chrome, Edge, or Safari).
2. Look for the "Install" icon in the address bar or select "Add to Home Screen" from your mobile browser's sharing menu.
